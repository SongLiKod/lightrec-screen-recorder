## 1. 产品概述
1.1 产品目标
复刻EV录屏完整能力，保留EV简洁清爽的交互体验；UI风格默认复刻EV扁平简约蓝色主题，同时支持【跟随系统、浅色、深色】三套主题切换。
底层音视频能力对齐EV会员全部功能，全局画板标注、鼠标增强、按键悬浮、三分屏课件录制、视频修复、局域网扫码直播全部原生内置，无需插件。

1.2 竞品对标基准
对标 EV录屏 Windows版（免费基础功能 + VIP会员全功能）
> EV技术背景参考：C++ + Qt Widgets + FFmpeg，自定义扁平化UI皮肤，无系统原生Mica材质。

1.3 目标用户
- 讲师/网课老师：课件录制、三分屏教学视频、录制时圈画重点
- 教程创作者：软件演示、操作教程、GIF素材导出
- 办公用户：会议录制、问题复现、定时录制会议
- 直播创作者：RTMP推流，边直播边本地存盘
- 普通用户：简单屏幕录制，保存操作流程

## 3. 功能需求
### 3.1 基础录制功能
1. 录制模式
    - 全屏录制：支持多显示器选择
    - 窗口录制：跟随目标窗口移动录制
    - 自定义选区录制：鼠标框选；**录制过程中可以拖动调整选区位置、大小**
2. 录制控制
    - 开始 / 暂停 / 继续 / 停止
    - 全局自定义快捷键
3. 音视频基础参数
    - 编码：H.264 / H.265，优先硬件编码 NVENC / AMF / QSV，硬件失败自动降级软编
    - 帧率：15/24/30/60fps可选
    - 输出容器：MP4
4. 文件管理
    - 录制列表：文件名、时长、文件大小、录制时间
    - 预览、打开保存目录、重命名、删除

### 3.2 会员专属Overlay实时叠加（核心，画面内容直接写入视频）
1. 实时桌面画板：画笔、箭头、矩形、圆形、直线、文字标注；颜色粗细调节、撤销、清空、一键隐藏画板
2. 按键悬浮显示：展示键盘按键、组合键（Ctrl+C等）；支持调整位置、字号、透明度
3. 鼠标光标增强：高亮外环、左右点击区分特效，调节大小颜色时长
4. 摄像头画中画：摄像头画面自由拖动缩放、镜像、调节透明度；内置布局模板：单屏、二分屏、三分屏（屏幕+摄像头+PPT辅助区域）

### 3.3 音频处理模块
1. 系统音频、麦克风独立双轨道录制，后期可以单独调节音量
2. 麦克风降噪、人声增益调节

### 3.4 内置视频工具箱（录制后处理）
全部内置，不需要第三方剪辑软件
1. 损坏录屏MP4修复（异常中断文件修复）
2. 视频变速导出：0.5x ~ 2.0x
3. 时间片段裁剪、画面裁切
4. 视频压缩转码，可控画质下缩小体积
5. 选中片段一键导出GIF
6. 水印：文字水印、图片水印；支持批量添加水印，水印方案保存预设

### 3.5 直播推流模块
1. RTMP推流直播：填写推流地址、密钥；**串流存盘（直播同时本地保存视频）**
2. 局域网本地直播：启动内网web服务，生成二维码+网页链接；支持至少10台设备同时扫码观看
3. 直播画面同步叠加画板、鼠标特效、摄像头画中画

### 3.6 任务与配置预设管理
1. 定时录制任务：设置开始/停止时间，自动启停；多条任务管理、启用关闭
2. 配置预设：保存整套参数（录制区域、帧率、水印、摄像头布局、音频参数、画笔样式），一键切换预设

### 3.7 附加扩展功能
1. 虚拟摄像头输出：将叠加后的录屏画面输出为虚拟摄像头，供会议软件调用
2. 断点续录：软件闪退崩溃后，缓存可恢复录制任务

## 4. UI & 主题需求
1. 默认UI风格：复刻EV录屏清爽扁平化风格，蓝色主色调，布局简洁，控件克制
2. 主题模式三选一：跟随系统 / 浅色 / 深色
    - 跟随系统：监听Windows系统主题变更，自动切换，无需重启软件
    - 浅色、深色独立配色方案
3. 适配Windows高DPI缩放（100%/125%/150%/175%/200%）
4. 字体：优先 Microsoft YaHei UI，备选Segoe UI
5. 录制悬浮工具栏：半透置顶悬浮条，可拖动，录制全程置顶

---

## 5. 非功能性需求
1. 性能：硬件编码模式下低CPU占用；支持连续2小时以上长时间录制，不崩溃、不丢帧
2. 兼容性：Win10 1903及以上、Win11 64位；兼容NVIDIA/AMD/Intel硬件编码
3. 稳定性：异常闪退时保留缓存，支持视频修复工具恢复
4. 隐私：录制内容默认本地存储；仅用户主动开启局域网直播才会启动本地web服务，不上传云端
5. 包体：轻量化，精简打包后控制在30MB以内

## 7. 验收标准
1. P0功能稳定运行，无高频崩溃
2. 所有Overlay叠加内容（画板、鼠标特效、按键、摄像头）可以正常写入最终视频文件
3. 硬件编码正常，60fps录制流畅无明显丢帧；硬件编码失败自动切换软编并提示用户
4. RTMP推流稳定，直播同时本地录像文件完整可播放
5. 主题切换正常，跟随系统模式自动响应Windows深浅色切换，高DPI界面无模糊错乱
6. 工具箱导出的MP4/GIF可以在主流播放器正常播放

---

## 8. 风险说明
1. 硬件编码：不同显卡驱动对NVENC/AMF/QSV支持存在差异，必须做降级兜底
2. 音频采集：部分笔记本声卡对双音轨采集支持不佳，增加备选采集方案
3. 局域网直播：受防火墙、路由器、内网网段限制，增加友好提示文案
4. 顶层全局Overlay绘制：全局置顶画板需要处理鼠标穿透、窗口置顶逻辑，容易和其他软件冲突
